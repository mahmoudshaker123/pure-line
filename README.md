# Pure Line Static Profile

موقع تعريفي Static لمؤسسة الخط النقي، مبني بملفات HTML وCSS وJavaScript فقط. يشمل خدمات المقاولات والمصاعد والسباكة والصرف والكهرباء والحريق والإنذار والتكييف.

## تشغيل محلي

```powershell
python -m http.server 8000
```

افتح `http://127.0.0.1:8000/`.

## النشر

النشر الموصى به هو Cloudflare Pages المجاني. راجع [دليل النشر](DEPLOYMENT.md).
